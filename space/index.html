Steering transformers
from the inside

Change what a language model "feels" by adding one vector to its hidden states while it writes. No prompt change, no fine-tuning. Tested on Qwen2.5-0.5B and on TinyGPT, a 12M-parameter GPT built from scratch for this project.

How it works

A transformer keeps one running vector per token, the residual stream. Every block reads it and adds its output back. Concepts like "happy" seem to be directions in this space.

1 · Contrastive examples

Sentences that differ only in the concept: "I loved the trip, it was wonderful" vs "I hated the trip, it was awful".

2 · Steering vector

Run both sets through the model; v = mean hidden state of the happy ones − mean of the sad ones, after block ℓ.

3 · Steer

While generating, a PyTorch forward hook adds α·v to the residual stream at every token. Weights and prompt stay unchanged.

4 · Control and measure

A random vector of the same length is added the same way. Text is scored for sentiment, perplexity (fluency) and repetition.

Results

Qwen: 50 neutral prompts × 2 samples per setting. TinyGPT: 30 story prompts × 2 samples. 40 new tokens, temperature 0.7.
